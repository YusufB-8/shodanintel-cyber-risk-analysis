# 🛡️ ShodanIntel - Cyber Risk Analysis Dashboard

A Python-based cyber threat intelligence project that collects, analyzes and visualizes publicly available exposure statistics from Shodan.

## 🚀 Features

- 🌍 Automated data collection with Shodan API
- 🧹 Data cleaning and preprocessing
- 📊 Risk scoring engine
- 🤖 AI-powered anomaly detection
- 📈 Interactive dashboard with Streamlit
- 🗺️ Global cyber risk visualization
- 🔍 CVE-based exposure analysis

---

## Tech Stack

- Python
- Shodan API
- Pandas
- NumPy
- Scikit-learn
- Plotly
- Streamlit
- Seaborn
